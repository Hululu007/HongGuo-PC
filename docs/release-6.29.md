# 红果短剧 6.29 发行回执

状态：版本候选 `6.29.0`，公开目标 `v6.29`。仅支持 Windows x64。

## 发布内容

- 改进在线播放失败提示与折叠诊断详情，分别显示当前取源路径、媒体读取、解码和首帧状态。
- 未确认原因的播放接口空响应不再推测为签名失败或设备鉴权异常；诊断信息不展示媒体 URL、query、签名、Cookie、设备 ID 或密钥。
- 不更改播放取源请求、设备参数、签名、来源顺序、重试策略或内容授权范围；没有新增 Android 游客 Provider。
- 本版本用于用户实机播放反馈，不宣称解决官方 Android 游客播放差异或完成完整播放验收。

## 验证与限制

- 本地 `npm test`：通过，含单元测试与 112 项平台检查。
- 本地 `npm run build:react`：通过。
- 公开 Release 的源代码测试、Windows x64 候选安装器、资产摘要及公开下载入口：待工作流执行并回填。
- 官方 Android 游客初始化、五部剧同网手机/电脑对照、Windows 安装包实际播放、首帧与连续观看、静音、切集、清晰度和恢复验收：未完成。安装器候选 smoke test 不代表这些播放验收。
- 发布资产按项目规则仅限 Windows x64 安装 EXE 与对应 `latest.yml`；不得据取源、媒体读取、解码或安装成功单独宣称整集播放成功。
