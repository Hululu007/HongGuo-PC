# 红果短剧 6.17

内部版本 `6.17.0`，计划公开标签 `v6.17`，仅面向 Windows x64。当前为发行准备状态；6.16 仍是上一正式版。本文件将在实际 CI 和发布完成后登记冻结源码、运行号与资产摘要。

## 更新内容

- 改进 App 播放接口空响应后的恢复：继续尝试当前 V5 接口，交替官方主、备主机，时间允许时更新匿名播放设备身份并重新签名，不再在该恢复路径降级到 legacy 接口。
- 模型请求最多五次，初次设备注册后的重试及 fallback 总预算为 20 秒。明确拒绝、取消以及原有分集和媒体校验边界保持有效。

排查依据、行为与局限见 [修复记录](fix-app-source-empty-response.md)。本版不承诺消除上游空响应，也不以此前小样本估计宣传成功率。

## 计划发行资产

正式发布时仅上传 `hongguo-downloader-6.17-win-x64-setup.exe` 与 `latest.yml`，保留 GitHub 自动生成的源码快照。发布前须核对源码 Test、Windows x64 候选、安装验收回执、安装器 SHA-256 与更新清单 SHA-512；本阶段尚无最终资产摘要。
