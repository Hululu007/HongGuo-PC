# 故障排查

## 导出诊断信息

打开“设置 → 配置文件位置 → 导出诊断信息”。文件包含版本、平台、运行时、任务状态、存储目录是否可用、代理模式、媒体工具和更新状态；不会主动写入代理密码、签名媒体地址或本地绝对路径。提交前仍应检查文件内容。

## 更新失败

1. 在“更新日志”中点击“重新检查”。
2. 如果能看到版本但下载失败，检查“设置 → 网络代理”，分别尝试跟随系统、手动代理或明确直连。
3. 安装前先暂停下载、合并、转码和维护任务；安装器会保留已校验下载，不会先删除旧版本。
4. 便携版、开发版和预览版不会覆盖当前运行文件，请从正式 Release 手动安装。

## FFmpeg/ffprobe 不可用

播放和真实解码检查需要匹配平台的 FFmpeg 与 ffprobe。缺少工具时，普通页面仍可打开，但真实解码、质量检查或兼容转码会失败。不要用彩条视频替代项目规定的真实红果下载素材。

## 存储失败

检查配置目录权限、下载目录挂载状态和可用空间。store 写失败会回滚到最后一次成功内容并暂停后续保存；不要删除原 JSON 文件。先保留文件，再提交诊断报告。

## 真实媒体验收边界

真实播放、画中画、连播和看完自动删除必须使用独立测试目录中随机下载的真实红果素材，全程静音。公开预览片段只能验证取源或解码工具，不能证明完整分集 GUI 行为。
