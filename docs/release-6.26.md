# 红果短剧 6.26 发行说明

状态：源码发行目标 `6.26.0`，公开版本 `6.26`，标签 `v6.26`。上一正式版本为 6.25。仅支持 Windows x64。

## 本轮范围：移除河马播放源

1. 河马从内置来源注册表、来源切换、全局搜索、发现片单、摇一摇抽签和账号页面移除；`src/native/hema.js` 适配器删除，并从 Electron 打包清单排除。红果保持固定开启，不可关闭。
2. 保留旧数据：已有观看历史、下载任务记录和本地视频文件不删除、不改写；旧记录继续按历史展示。
3. 旧 `hema:` 标识失败关闭：在线搜索、目录、分集解析、取源、播放准备、兼容转码、媒体恢复重试和继续下载在入口即返回「河马来源已移除」，不会改投红果、西饭或采集源。
4. 已下载的本地完整文件仍可经本地播放路径使用；在线重新取源一律拒绝，避免旧记录被静默替换成其他来源的内容。

## 回归

- `npm test` 通过：Node 单元测试与 111 项平台检查全部通过。
- 媒体恢复回归 36 项通过，覆盖旧 `hema:` 标识在任何恢复取源前即失败，以及西饭/采集源的地址刷新、拒绝状态和 HLS 分支。
- 来源与搜索聚焦单测 38 项通过；`check-hema.cjs`、`check-hema-browse.cjs`、`check-source-integration.cjs`、`check-catalog-routing.cjs` 验证河马未注册且各在线入口拒绝旧标识。
- `npm run build:react` 通过；`scripts/check-release-version.cjs` 覆盖 6.26 版本对与下载文件名。
- 本工作区当时缺少依赖时曾出现 `axios`/`esbuild` 缺失，恢复依赖后上述结果均为实际执行通过。

## 验收边界与已知限制

- 本轮未进行实时上游播放验收：没有重新抽样各站点的可用性，也没有 GUI 播放、真机托盘或安装器升级验收。此前的现场抽样记录与失败项见 [来源稳定性记录](source-stability-2026-11-20.md)。
- 红果完整分集取源、硕博/暴风/旺旺等站点的网络故障属未解决的外部问题，本版本不宣称已修复。
- 第三方站点接口可能随时变化；本版本只保证河马移除后的本地路由与失败关闭行为。
- 公开视频接口调研结论见 [搜索来源分析](search-sources-analysis.md)：未发现可合法、稳定替代各短剧来源取址的通用播放接口。
