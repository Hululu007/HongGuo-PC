## 已修复的本地问题

1. **Windows 加密 HLS 无法转换。**临时清单原先写入 Windows 绝对路径，FFmpeg 在解析 `URI` 属性时吞掉反斜杠，报无法打开密钥文件。两次随机真实红果素材复现后，将清单、分片及密钥引用统一为同一临时目录内的程序生成相对文件名。保持公网地址、重定向、私网拒绝、完整性及临时空间检查。
2. **其他来源地址过期后不重新取址。**原恢复轮次仅对红果数字分集编号启用。现在已知的西饭、河马和采集源编号也可在可恢复的媒体失败后重新取得同一分集地址，最多三轮、最多四次媒体尝试；未知编号不获得自动恢复。每次重取仍经过提供方当前权限检查，已经开始的媒体不会混用不同地址的字节偏移。
3. **旧备用线路耗尽恢复预算。**存在多条旧地址时，为一次新取址保留媒体尝试机会，避免四条过期候选耗完预算而完全跳过刷新。
4. **拒绝状态错误换线。**非红果来源的 HTTP 401/403/429 立即停止，不继续重取、换候选或调整传输画像；HLS 的显式状态码向上传递。缺失或无法启动 FFmpeg 使用本地工具错误分类，停止无效的重复取源。
5. **默认关闭的采集源仍能被旧编号访问。**访问门禁现在与界面采用相同的 `defaultOn` 与显式开关规则；默认关闭、显式开启、显式关闭均有离线回归。
6. **歧义分集标题可能误换集。**同一线路多次出现“正片”等相同标题时，不将这种歧义匹配用于自动备用；保留精确请求的线路和位置，只在两端分集键均唯一时跨线匹配。

没有增加远程代码、自动执行规则更新、猜测接口或无限重试。上述恢复只处理本地路径问题、地址过期和部分临时传输故障；第三方停服、网络不可达、接口协议改变或访问拒绝仍可能需要提供方恢复或有依据的代码维护。
